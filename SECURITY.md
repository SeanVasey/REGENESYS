# Security Policy

Thank you for helping keep REGENESYS secure.

## Supported Versions

Security updates are currently provided for the latest commit on `main`.

## Reporting a Vulnerability

Please **do not** open public GitHub issues for vulnerabilities.

Instead, report privately to: **security@regenesys.example** (placeholder; replace with a monitored inbox).

When reporting, include:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigations

We will acknowledge receipt within 3 business days and provide status updates as triage progresses.
